# JavaScript Practice

This is a simple JavaScript practice project created to practice basic JavaScript concepts and understand how different loops, functions, and arrays work.

## Topics Practiced

* While Loop
* Countdown using a While Loop
* For Loop
* Functions
* Arrow Functions
* Arrays
* `push()` method
* Console Output

## Technologies Used

* HTML5
* JavaScript

## Project Structure

```text
JavaScript-Practice/
├── index.html
├── a.js
```

## File Overview

### `index.html`

Contains the basic HTML page and connects the JavaScript file.

### `a.js`

Contains all the JavaScript practice code, including loops, functions, arrow functions, and array operations.

## How to Run

Clone the repository:

```bash
git clone "YOUR_REPOSITORY_URL"
```

For example:

```bash
git clone https://github.com/Ishratalib/JavaScript-Practice.git
```

Open the project folder and run `index.html` using a browser or Live Server.

## Console Output

This project does **not display the JavaScript results directly on the webpage**.

The JavaScript results are printed in the **browser Console** using `console.log()`.

To view the output:

1. Open `index.html` in the browser.
2. Press **F12**.
3. Open the **Console** tab.
4. You will see the JavaScript output there.

The program produces outputs for:

* Sum of numbers from 1 to 5
* Countdown from 5 to 1
* Numbers multiplied by 2
* Tea-making function
* Total calculation using an arrow function
* Updated cities array

## Purpose

The purpose of this project is to practice and understand fundamental JavaScript concepts through small examples and console-based exercises.
